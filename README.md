# Bilal Saeed — Portfolio

A responsive personal portfolio highlighting my work in AI, workflow automation, and full-stack development.

## Run locally

Open `index.html` in a browser. The résumé and portrait are stored alongside the page.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub Pages will publish `index.html` from the repository root.
